# ClaimBack Frontend

A polished React + Vite frontend based on the provided ClaimBack visual reference.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Notes

- No database or backend is required for this frontend demo.
- Mock interactions are included for upload/evidence, attack simulation, claim generation, navigation, theme toggle, and quick actions.
- The UI is structured so the mocked actions can later be replaced with FastAPI API calls.
- Backend integration should be added through a dedicated API layer rather than directly inside UI components.
